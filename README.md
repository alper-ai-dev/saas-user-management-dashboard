# SaaS User Management Dashboard

A responsive SaaS administration portfolio project for managing users, roles, subscription plans and account status.

## Features
- Create, edit and delete users
- Role management: Admin, Manager, Member
- Subscription plans: Free, Pro, Business
- Account status management
- User and email search
- Role and plan filters
- Active-user metrics
- Monthly recurring revenue (MRR) demo calculation
- Persistent browser data with Web Storage
- Responsive admin dashboard

## SaaS Model
The application models common SaaS administration concepts including user lifecycle, role-based organization, subscription tiers, account status and recurring-revenue metrics. It is a public portfolio demo and does not process real payments or provide production authentication.

## Stack
HTML5, CSS3, JavaScript, Web Storage API, responsive UI.
